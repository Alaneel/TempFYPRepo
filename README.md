# Real Estate Scrapers Collection

This project contains a collection of web scrapers for Singapore real estate portals.

## Scrapers

- **[PropertyGuru](propertyguru/README.md)**: Comprehensive scraper with incremental update and agent detail support.
- **[EdgeProp](edgeprop/README.md)**: Scraper for EdgeProp.sg listings.
- **[99.co](99co/README.md)**: Scraper for 99.co listings.
- **[SRX](srx/README.md)**: Advanced concurrent scraper for SRX.

## Setup

1. **Install Dependencies**

   ```bash
   pip install -r requirements.txt
   playwright install chromium
   ```

2. **Run Scrapers**
   Navigate to the respective directory and follow the instructions in its README.
