\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Singapore's real estate market is divided into a strictly regulated public sector (Housing and Development Board (HDB)) and a private market, but relevant information is scattered across four competing portals, lacking a unified structure. This report outlines how to design and implement a system to integrate data from these four portals into a unified platform, focusing on data scanning, deduplication, ranking, and search capabilities.

Developed as part of a team effort, the system features robust web scraping pipelines aggregating live data from major property portals (PropertyGuru, 99.co, EdgeProp, and SRX). The author personally designed and implemented the PropertyGuru scraper—the largest data source comprising over 53,000 listings—as well as the centralized aggregation and deduplication pipeline. Our composite key deduplication algorithm, employing a title-fallback strategy, achieves 95.5\% address field coverage, successfully extends to various data structures, and eliminates cross-platform duplication.

Based on this unified dataset, the author implemented advanced analytical capabilities and a user-friendly application suite. Eight Gradient Boosting Valuation (XGBoost) models targeting specific market segments exhibited a low mean absolute percentage error (MAPE) of 8.9\%. Integrating SHAP for interpretability, the models achieved a 70\% error reduction over the baseline. An ablation study further confirmed that the model's logic aligns with real-world market factors. Specifically, removing \texttt{property\_age} resulted in a 130\,pp increase in MAPE for HDB Sales, while Landed Sales only saw a 1.2\,pp rise. This difference aligns with Singapore's CPF lease-eligibility policy and has resulted in a unique demand-side discontinuity in the stock of older HDB flats. This highlights the rationality of this model's feature utilisation within its economic structure. Furthermore, the LLM-powered search engine achieved a 96.4\% F1 score in translating queries to database filters, with a blind evaluation (18 queries) confirming an adjusted F1 of $\sim$91\%. Three agentic enhancements were layered on top: multi-district geographic resolution, progressive filter relaxation with zero-result prevention, and LLM-generated fallback explanations. A multi-turn chat assistant rounds out the UI, providing property valuations driven by XGBoost and SHAP importance factors. Offline evaluation of 42 interactions covering three real estate segments confirmed a 93\% fact accuracy and 100\% response relevance. The system is built on a decoupled architecture, leveraging a FastAPI backend for high-concurrency data serving and a Next.js frontend for an interactive user experience. This setup transforms raw real-time market feeds into actionable, multi-dimensional real estate insights.
