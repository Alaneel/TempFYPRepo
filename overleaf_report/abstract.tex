\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This report details the development of an end-to-end AI-driven real estate analysis system tailored for the Singapore housing market. Addressing the industry-wide challenges of data fragmentation and the complex interplay between the public (HDB) and private residential sectors, this project establishes a unified market intelligence platform.

Developed as part of a team effort, the system features robust web scraping pipelines aggregating live data from major property portals (PropertyGuru, 99.co, EdgeProp, and SRX). The author personally designed and implemented the PropertyGuru scraper—the largest data source comprising over 53,000 listings—as well as the centralized aggregation and deduplication pipeline. A composite-key deduplication algorithm with a title-fallback strategy achieved 95.5\% address-field coverage, successfully harmonizing disparate data structures and eliminating cross-platform duplicates.

Building upon this unified dataset, the author implemented a suite of advanced analytics and user-facing applications. This includes eight segment-specific gradient-boosted valuation models (XGBoost) achieving a Mean Absolute Percentage Error (MAPE) as low as 8.9\%, complete with SHAP-based interpretability—a 70\% reduction relative to a mean baseline. Furthermore, an LLM-powered natural language search engine was integrated, successfully translating free-text user queries into structured database filters with a 96.4\% F1 score. Three agentic enhancements were layered on top: multi-district geographic resolution, progressive filter relaxation with zero-result prevention, and LLM-generated fallback explanations. A multi-turn AI valuation chat assistant, grounded in per-listing XGBoost estimates and SHAP factors, completes the user-facing feature set; an offline evaluation across 42 interactions spanning three property segments confirms 93\% factual consistency and 100\% response relevance. The complete system is deployed via a local FastAPI backend and a Next.js frontend, transforming raw market data into actionable, multi-dimensional real estate insights. Crucially, a feature ablation study revealed that the trained models implicitly learnt Singapore's Central Provident Fund (CPF) lease-eligibility policy purely from asking-price distributions without explicit encoding, demonstrating the potential for using gradient-boosted models on listing data as empirical probes for regulatory market mechanisms.
