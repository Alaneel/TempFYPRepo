\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Singapore's real estate market is divided into a strictly regulated public sector (Housing and Development Board (HDB)) and a private market, but relevant information is scattered across four competing portals, lacking a unified structure. This report outlines how to design and implement a system to integrate data from these four portals into a unified platform, focusing on data scanning, deduplication, ranking, and search capabilities.

Developed as part of a team effort, the system features robust web scraping pipelines aggregating live data from major property portals (PropertyGuru, 99.co, EdgeProp, and SRX). The author personally designed and implemented the PropertyGuru scraper—the largest data source comprising over 53,000 listings—as well as the centralized aggregation and deduplication pipeline. Our composite key deduplication algorithm, employing a title-fallback strategy, achieves 95.5\% address field coverage, successfully extends to various data structures, and eliminates cross-platform duplication.

Building upon this unified dataset, the author implemented a suite of advanced analytics and user-facing applications. Eight segment-specific gradient-boosted valuation models (XGBoost) achieve a Mean Absolute Percentage Error (MAPE) as low as 8.9\%, complete with SHAP-based interpretability---a 70\% reduction relative to a mean baseline. A feature ablation study further validated model behaviour against known domain priors: removing \texttt{property\_age} causes a 130\,pp MAPE increase in HDB Sale but only 1.2\,pp in Landed Sale, a pattern consistent with Singapore's CPF lease-eligibility policy creating a demand-side discontinuity specific to ageing HDB stock---confirming that the model's feature utilisation reflects economically meaningful structure. An LLM-powered natural language search engine translates free-text user queries into structured database filters with a 96.4\% F1 score, confirmed by an independent 18-query blind evaluation yielding an adjusted F1 of $\sim$91\% with zero complete failures. Three agentic enhancements were layered on top: multi-district geographic resolution, progressive filter relaxation with zero-result prevention, and LLM-generated fallback explanations. A multi-turn AI valuation chat assistant, grounded in per-listing XGBoost estimates and SHAP factors, completes the user-facing feature set; an offline evaluation across 42 interactions spanning three property segments confirms 93\% factual consistency and 100\% response relevance. The complete system is deployed via a local FastAPI backend and a Next.js frontend, transforming raw market data into actionable, multi-dimensional real estate insights.
